# Report preview slides (landing carousel)

Drop cropped screenshots of real report slides here, named `1.png`, `2.png`, `3.png`,
… (in order). The landing's "Spotify-Wrapped Style Report" carousel probe-loads them
and shows them with ← → arrows. If none are present, it falls back to a few styled
mock slides.

- Take them from a real report (e.g. open a report, screenshot a card, crop to the card).
- Any aspect ratio is fine; they render full-width inside the carousel.
- Up to 8 slides (`1.png` … `8.png`).
